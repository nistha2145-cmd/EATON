# 🍔 EatOn – Food Delivery Website

EatOn is a simple and user-friendly food delivery website designed to help users discover restaurants, browse food items, add items to their cart, and place food orders.

🌐 **Live Website:**  
https://nistha2145-cmd.github.io/EATON/

---

## 📌 About the Project

EatOn is a front-end food delivery web application developed using HTML, CSS, and JavaScript.

The website provides a simple food-ordering experience where users can:

- Search for restaurants and dishes
- Browse popular restaurants
- Filter food by category
- View restaurant menus
- Add food items to the cart
- Increase or decrease item quantities
- View the total order amount


The project is designed as a front-end implementation and does not use a backend database or real payment gateway.

### 🔍 Search
